# Contributing

Issues and pull requests are welcome: bug reports, fixes, and support for more Rails versions and association shapes. For a larger change, open an issue first so the direction can be agreed before you write it.

Open pull requests against `develop`. The development setup, branch naming, commit messages and the checks CI runs are in [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Rights in your contribution

A contribution you send in a pull request is licensed under the same [MIT License](LICENSE) as the rest of the gem; there is no CLA to sign. Send only work that is your own, or that is under a license compatible with MIT, and say where it comes from when it is not yours.
